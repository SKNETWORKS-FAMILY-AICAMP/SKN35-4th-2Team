## 로컬 실행 방법 (요약)

API 키(OpenAI, Pinecone)와 DB 접속 정보는 저장소에 없고 별도로 전달한다. 자세한 설명은 저장소의 `README.md` 6장.

```bash
uv sync
copy .env.example back\.env        # back/.env에 키와 DB 정보를 채운다
# 재정렬 모델 폴더를 back/data/onnx/ 에 둔다 (용량 때문에 저장소에서 제외)
uv run python back/manage.py runserver
```

브라우저에서 `http://127.0.0.1:8000`을 연다. 자동 테스트: `uv run python back/manage.py test chat` (143개)

## 알려진 한계

- HTTP로 서비스해 비밀번호가 암호화되지 않고 전달된다(도메인이 없어 HTTPS 미적용).
- 문서 범위 밖의 일반 개발 질문은 문서 검색 없이 일반 답변으로 처리되며 출처가 붙지 않는다.
- 이미지 파일은 서버 디스크에 저장되고 DB에는 경로만 있어, 로컬과 서버가 같은 DB를 쓰면 다른 쪽에서 올린 이미지는 보이지 않는다.
- 관리자 화면 없음, 로그아웃의 서버 측 무효화 불가(쿠키는 24시간 안에 만료).
